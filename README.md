# SFind
# Description:
SFind is a tool to find directories on websites using threading and requests
# Usage:
When running the script, the first argument should be the target URL, and the second should be your wordlist, eg: "python SFind.py https://example.com C:/wordlist_example" for windows, for linux "python3 SFind.py https://example.com ~/wordlist_example" for linux
